Sol Workspace

개인이 자기 구글 계정을 정리하려고 직접 쓰는 명령줄 도구

무엇을 하는 도구인가

Sol Workspace는 운영자 한 사람이 본인 노트북에서 실행하는 명령줄 도구입니다. 본인의 구글 계정에 있는 메일·문서·일정을 읽어 노트와 문서로 정리합니다. 배포하거나 판매하지 않고, 가입 절차도 없으며, 운영자 외의 사용자를 받지 않습니다.

어떤 데이터에 접근하나

구글 로그인 시 아래 범위의 권한을 요청합니다. 모두 운영자 본인 계정에만 해당합니다.

Gmail메일을 읽고 초안을 만들고 라벨을 정리합니다
Drive · Docs · Sheets · Slides문서를 읽고 만들고 고칩니다
Calendar · Tasks일정과 할 일을 읽습니다
계정 기본 정보로그인한 계정이 본인인지 확인합니다

데이터는 어디로 가나

어디로도 보내지 않습니다. 도구는 운영자의 컴퓨터에서 돌고, 통신 상대는 구글 API 서버 하나뿐입니다. 별도의 서버, 데이터베이스, 분석 도구를 두지 않습니다. 자세한 내용은 개인정보처리방침에 있습니다.

개인정보처리방침 서비스 약관

In English

Sol Workspace is a command-line tool that one person runs on their own laptop to organize their own Google account — reading mail, documents, and calendar entries and turning them into notes and files. It is not distributed or sold, there is no sign-up, and it has no users other than its operator.

It requests Gmail, Drive, Docs, Sheets, Slides, Calendar, and Tasks scopes, all against the operator's own account. Data is never sent anywhere: the tool runs locally and talks only to Google's own API servers. There is no separate backend, database, or analytics.
