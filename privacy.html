Sol Workspace · 시행일 2026년 8월 30일

1. 이 문서가 다루는 범위

Sol Workspace(이하 "이 도구")는 운영자 한 사람이 본인 컴퓨터에서 실행하는 명령줄 도구입니다. 이 문서는 이 도구가 구글 계정 데이터를 어떻게 다루는지를 설명합니다. 이 도구에는 운영자 외의 이용자가 없고, 회원가입·결제·문의 창구가 없습니다.

2. 접근하는 정보와 이유

구글 OAuth 동의 화면에서 아래 권한을 요청합니다. 모두 동의한 본인 계정에만 적용됩니다.

Gmail (gmail.modify)메일 본문과 헤더를 읽고, 초안을 만들고, 라벨을 붙입니다. 이 도구는 사용자가 명시적으로 지시하지 않으면 메일을 발송하지 않습니다.
Drive작업 대상 파일을 열고 결과 파일을 저장합니다.
Docs · Sheets · Slides문서·스프레드시트·슬라이드를 읽고 만들고 수정합니다.
Calendar일정을 읽어 하루 기록에 넣습니다.
Tasks할 일 목록을 읽습니다.
openid · userinfo.email · userinfo.profile로그인한 계정이 본인인지 확인합니다.

3. 저장과 보관

  • 인증 토큰은 운영자 컴퓨터의 macOS 키체인에 저장됩니다. 외부로 전송되지 않습니다.
  • 불러온 내용(메일 본문, 문서 내용 등)은 작업하는 동안만 메모리에 있거나, 운영자가 지시한 경우 운영자 컴퓨터의 로컬 파일로 저장됩니다.
  • 이 도구는 자체 서버나 데이터베이스를 두지 않습니다. 통신 상대는 구글 API 서버뿐입니다.
  • 보관 기간은 운영자가 로컬 파일을 지우거나 권한을 철회할 때까지입니다.

4. 제3자 제공

제공하지 않습니다. 이 도구는 가져온 데이터를 판매·양도·공유하지 않고, 광고에 쓰지 않으며, 분석 도구나 추적 스크립트를 사용하지 않습니다. 인공지능 모델의 학습 데이터로도 쓰지 않습니다.

5. 구글 API 서비스 사용자 데이터 정책

이 도구가 구글 API로 받은 정보의 이용과 다른 앱으로의 전송은 Google API Services User Data Policy를 따르며, 여기에는 제한적 사용(Limited Use) 요건이 포함됩니다.

6. 권한 철회

구글 계정 설정의 서드파티 앱 및 서비스에서 언제든 이 도구의 접근 권한을 철회할 수 있습니다. 철회하면 저장된 토큰이 즉시 무효가 됩니다.

홈 서비스 약관

Privacy Policy (English)

Effective 30 August 2026. Sol Workspace is a command-line tool run by a single operator on their own computer. It has no users other than its operator, and there is no sign-up, payment, or support desk.

What it accesses

Through Google OAuth the tool requests Gmail (gmail.modify), Drive, Docs, Sheets, Slides, Calendar, Tasks, and basic account identity. All of these apply only to the account that granted consent. Gmail access is used to read messages, create drafts, and apply labels; the tool does not send mail unless explicitly instructed.

Storage and retention

OAuth tokens are stored in the macOS Keychain on the operator's computer and are never transmitted elsewhere. Retrieved content stays in memory for the duration of a task, or is written to local files on that same computer when the operator asks for it. The tool operates no server or database of its own; the only network endpoint it contacts is Google's own API. Data is retained until the operator deletes the local files or revokes access.

Sharing

None. Data obtained through these APIs is never sold, transferred, or shared, is not used for advertising, is not fed to analytics or tracking services, and is not used to train AI models.

Limited Use

The use and transfer of information received from Google APIs to any other app adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access & contact

Access can be revoked at any time at Google Account permissions; stored tokens become invalid immediately. Questions may be sent to eunss225@gmail.com. Changes to this policy are published on this page with an updated effective date.
